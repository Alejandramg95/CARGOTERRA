# CARGOTERRA

Sitio corporativo en español. Conserva la identidad azul y plateado, logotipo e imágenes. No inventes teléfonos, tarifas, certificaciones, capacidades ni clientes.

La rama main contiene CARGOTERRA 2.0; version-original conserva Manzanillo. Archivos editables en dist/. npm start abre la vista local; npm run check revisa sintaxis.

No publicar ni cambiar el acceso del sitio sin autorización explícita de Alejandra. Preparar cambios para revisión. Guardar código en GitHub no actualiza Sites automáticamente.

El formulario prepara un correo para contacto@cargoterra.com.mx, no tiene backend de envío. No guardar datos personales ni credenciales en el repositorio.
